# MotiPad website

Official site: https://ezio1983.github.io/motipad-website/

This repository contains the public static website only. It does not contain the MotiPad iOS or Windows application source code.

## Publish

Upload all contents of this folder to the repository root. In Settings → Pages, choose Deploy from a branch, main, / (root), then Save.

The site supports Traditional Chinese, English, French, German, Japanese, Korean, Simplified Chinese, Spanish and Brazilian Portuguese. The root entry chooses a supported browser language and falls back to English. Direct language URLs retain the selected language. Language menus work without JavaScript.

## Downloads

Official App Store and Windows installer URLs have not been provided yet. The website correctly says the download links are coming soon. Windows installers can be uploaded to this repository’s Releases once ready.
